# 论文绘图任务背景与实施规范

## 一、任务背景

用户为计算机专业硕士研究生，目前正在完成学术论文。论文中需要绘制多种实验图，主要包括：

* 参数敏感性折线图；
* 消融实验或解析实验折线图；
* 不同方法性能对比柱状图；
* 稀疏性分组实验图；
* 其他适合在计算机学术论文中展示的实验结果图。

绘图工作的目标不仅是正确展示数据，还需要保证论文中所有图表在配色、字体、线型、图例、网格、尺寸和导出方式等方面具有统一风格。

用户已经决定采用以下技术路线：

> **Python + Matplotlib**

必要时可以辅助使用：

* NumPy：组织数值数据；
* Pandas：读取和整理 CSV、Excel 或表格数据；
* Matplotlib：完成最终绘图、排版和导出。

原则上不依赖 Seaborn 等会显著改变默认视觉风格的绘图库，除非确有必要。

---

## 二、参考风格来源

用户上传了多张师兄论文中已经完成的实验折线图，后续自己的论文绘图需要尽量与这些图保持一致。

目标不是简单地“画得好看”，而是：

> 让用户论文中的图和师兄论文中的图看起来像由同一套代码、同一个人或同一个课题组绘制。

从参考图片观察，师兄的图主要使用 Matplotlib 默认视觉体系，并在此基础上固定了线宽、marker、字号、网格和图例等参数。

参考图片中存在若干重复副本，实际展示的是若干组相近的折线图风格。当前上传的图片主要为折线图，尚未获得明确的师兄柱状图样例。

---

## 三、方案可行性结论

已经确认：

> 使用 Python 和 Matplotlib，可以较高程度复刻师兄现有图表的整体视觉效果。

具体分为三个层面。

### 1. 风格一致

可以稳定复刻以下内容：

* 画布尺寸和宽高比；
* 蓝、橙、绿的默认配色；
* 虚线线型；
* 折线宽度；
* 数据点 marker 的形状和大小；
* 坐标轴标签字号；
* 坐标刻度字号；
* 灰色横纵网格；
* 白色背景；
* 四周坐标轴边框；
* 图例的圆角、阴影和位置；
* PDF、PNG 的导出效果。

这一层面基本没有技术障碍。

### 2. 肉眼效果一致

在数据、坐标范围和文字内容确定后，可以将最终结果调整到：

> 放入论文后，肉眼看起来和师兄的图几乎没有明显风格差异。

这已经能够满足论文整体风格统一的要求。

### 3. 像素级完全一致

暂不承诺未经调试即可达到像素级完全相同，因为像素级结果可能受到以下因素影响：

* Matplotlib 版本；
* Python 环境；
* 操作系统；
* 字体文件及字体版本；
* 后端渲染方式；
* DPI；
* `tight_layout`；
* `constrained_layout`；
* `bbox_inches="tight"`；
* 师兄原始代码中未展示的细节参数。

如确实需要像素级逼近，可以通过将生成图与参考图反复对照、逐项微调来实现。

论文实际使用中，没有必要追求逐像素完全一致，整体风格、字号层级和视觉语言一致即可。

## 四、参考图的视觉风格分析

### 1. 画布尺寸

参考图片的宽高比例约为：

```text
8 : 5
```

建议默认使用：

```python
fig, ax = plt.subplots(figsize=(8, 5), dpi=100)
```

预览图大致对应：

```text
800 × 500 像素
```

后续论文中若使用双栏排版，可以在保持比例的前提下调整图像尺寸，但各张图应尽量统一。

---

### 2. 配色

参考图基本使用 Matplotlib 默认颜色循环的前三种颜色：

```python
蓝色：#1f77b4
橙色：#ff7f0e
绿色：#2ca02c
```

对应：

```python
colors = ["#1f77b4", "#ff7f0e", "#2ca02c"]
```

如果曲线数量超过三条，可以继续使用 Matplotlib 默认颜色循环，但应避免颜色过多导致混乱。

后续默认规则：

* 第一条方法：蓝色；
* 第二条方法：橙色；
* 第三条方法：绿色。

---

### 3. 折线样式

参考图中的折线通常具有以下特点：

```python
linestyle = "--"
linewidth = 3
markersize = 11 或 12
```

推荐默认值：

```python
linewidth=3
markersize=12
linestyle="--"
```

折线不宜过细，因为图片放入论文后会缩小。

---

### 4. Marker 形状

参考图中常用的 marker 包括：

```python
"s"  # 正方形
"o"  # 圆形
"^"  # 向上三角形
"v"  # 向下三角形
```

常见组合有：

```python
["s", "^", "o"]
```

或者：

```python
["^", "v", "o"]
```

marker 不仅用于美观，也可以确保图表在黑白打印时仍然能够区分不同方法。

建议同一篇论文中保持方法和 marker 的对应关系稳定。

---

### 5. 字体

参考图看起来主要采用 Matplotlib 默认字体体系，接近：

```python
font.family = "DejaVu Sans"
```

当前不建议强制改成 Times New Roman，否则可能破坏与参考图的统一性。

大致字号如下：

```text
坐标轴标题：22～24 pt
坐标轴刻度：18～20 pt
图例文字：20～21 pt
```

建议基础配置：

```python
axes.labelsize = 24
xtick.labelsize = 20
ytick.labelsize = 20
legend.fontsize = 21
```

如果坐标轴标题过长，可以适当缩小，例如：

```python
fontsize=18 或 20
```

个别较长的纵坐标标题可以使用粗体，但不应强制所有图都使用粗体。

---

### 6. 网格线

参考图开启了横向和纵向网格。

建议参数：

```python
ax.grid(
    True,
    color="#b0b0b0",
    linewidth=0.8,
    alpha=1.0
)
```

同时使用：

```python
ax.set_axisbelow(True)
```

使网格线位于折线和 marker 的下方。

对于柱状图，可以根据视觉效果只保留纵轴方向的横向网格：

```python
ax.grid(axis="y")
```

---

### 7. 背景和边框

参考图具有以下特点：

* 图片背景为纯白；
* 坐标区域背景为纯白；
* 上、下、左、右四条坐标轴边框均保留；
* 边框宽度较细。

推荐：

```python
"figure.facecolor": "white"
"axes.facecolor": "white"
"axes.linewidth": 0.8
```

不要默认去除顶部和右侧边框。

---

### 8. 图例

参考图中的图例特征十分明显：

* 白色背景；
* 灰色边框；
* 圆角；
* 带阴影；
* 字号较大；
* 根据数据分布放置在左下角或右下角。

建议参数：

```python
ax.legend(
    loc="lower left",
    fontsize=21,
    frameon=True,
    fancybox=True,
    shadow=True,
    framealpha=0.95
)
```

图例位置不能机械固定，应优先选择不遮挡曲线的位置：

```python
loc="lower left"
loc="lower right"
loc="upper left"
loc="best"
```

参考图多数使用左下角，部分图使用右下角。

---

### 9. 坐标刻度格式

参考图中的纵坐标经常保留一位小数，例如：

```text
0.0
-10.0
-20.0
```

可使用：

```python
from matplotlib.ticker import FormatStrFormatter

ax.yaxis.set_major_formatter(
    FormatStrFormatter("%.1f")
)
```

是否保留一位小数应根据具体指标决定。

例如：

* 相对变化百分比：适合一位小数；
* Recall、NDCG 的绝对值：可能需要三位或四位小数；
* 分组编号或整数：不应强制显示小数。

## 五、默认 Matplotlib 全局配置

后续 Codex 可以将下面的配置作为统一基础。

```python
import matplotlib.pyplot as plt

plt.rcParams.update({
    "font.family": "DejaVu Sans",

    "figure.facecolor": "white",
    "axes.facecolor": "white",

    "axes.linewidth": 0.8,
    "axes.labelsize": 24,

    "xtick.labelsize": 20,
    "ytick.labelsize": 20,

    "lines.linewidth": 3,
    "lines.markersize": 12,

    "axes.grid": True,
    "grid.color": "#b0b0b0",
    "grid.linewidth": 0.8,
    "grid.alpha": 1.0,

    "legend.fontsize": 21,
    "legend.fancybox": True,
    "legend.framealpha": 0.95,
    "legend.shadow": True,

    "pdf.fonttype": 42,
    "ps.fonttype": 42,
})
```

注意：

* 这是一套默认配置，不是所有图都必须完全照搬；
* 过长的标签、较多的方法数量或较小的子图需要适当缩小字号；
* 图例位置和坐标范围必须根据数据调整；
* 任何修改都应保持整体视觉体系不变。

## 六、默认折线图代码结构

Codex 后续生成折线图时，可以采用以下结构。

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import FormatStrFormatter


x = np.array([0.00, 0.05, 0.10, 0.15, 0.20, 0.25])

method_1 = np.array([0.0, -3.2, -5.8, -8.5, -11.8, -14.3])
method_2 = np.array([0.0, -4.7, -7.8, -11.5, -14.9, -17.7])
method_3 = np.array([0.0, -13.5, -16.3, -19.7, -24.8, -31.0])


fig, ax = plt.subplots(figsize=(8, 5), dpi=100)

ax.plot(
    x,
    method_1,
    linestyle="--",
    marker="s",
    linewidth=3,
    markersize=12,
    label="Method 1"
)

ax.plot(
    x,
    method_2,
    linestyle="--",
    marker="^",
    linewidth=3,
    markersize=12,
    label="Method 2"
)

ax.plot(
    x,
    method_3,
    linestyle="--",
    marker="o",
    linewidth=3,
    markersize=12,
    label="Method 3"
)

ax.set_xticks(x)
ax.set_ylabel("Relative NDCG@20 (%)", fontsize=24)

ax.tick_params(
    axis="both",
    which="major",
    labelsize=20
)

ax.grid(
    True,
    color="#b0b0b0",
    linewidth=0.8,
    alpha=1.0
)

ax.set_axisbelow(True)

ax.yaxis.set_major_formatter(
    FormatStrFormatter("%.1f")
)

ax.legend(
    loc="lower left",
    fontsize=21,
    frameon=True,
    fancybox=True,
    shadow=True,
    framealpha=0.95
)

fig.tight_layout()

fig.savefig(
    "figure.pdf",
    bbox_inches="tight"
)

fig.savefig(
    "figure.png",
    dpi=600,
    bbox_inches="tight"
)

plt.show()
```

## 七、柱状图的处理原则

当前提供的参考图片主要为折线图，尚无明确的师兄柱状图参考，因此暂时只能根据折线图的整体视觉语言推导柱状图风格。

柱状图应保持：

* 相同画布比例；
* 相同字体体系；
* 相同蓝、橙、绿配色；
* 白色背景；
* 灰色网格；
* 相同图例风格；
* 相同边框样式；
* 相近的字号层级。

建议柱状图默认只开启横向网格：

```python
ax.grid(
    axis="y",
    color="#b0b0b0",
    linewidth=0.8,
    alpha=1.0
)
```

柱状图的以下参数需要根据实际数据和后续参考图再确定：

* 柱宽；
* 柱间距；
* 分组间距；
* 是否带黑色边框；
* 是否使用纹理 hatch；
* 是否标注具体数值；
* 是否突出 Ours；
* 图例放置位置；
* 是否使用误差棒。

如果后续获得师兄的柱状图，应优先以实际参考图重新校准。

## 十、验收标准

生成的图应满足以下要求。

### 风格方面

* 与师兄参考图属于同一视觉体系；
* 默认使用 Matplotlib 蓝、橙、绿；
* 折线较粗；
* marker 较明显；
* 字号在论文缩放后仍清晰；
* 图例具有圆角和阴影；
* 背景为白色；
* 网格为灰色；
* 四周坐标轴边框保留。

### 版式方面

* 坐标标题不被裁切；
* 图例不遮挡关键曲线；
* 刻度不重叠；
* 留白适中；
* 不出现过度拥挤；
* 不出现无意义的小数位；
* 多张图的尺寸、字号和线宽尽量一致。

### 输出方面

* PDF 为主要论文文件；
* PNG 至少 600 DPI；
* 使用 `bbox_inches="tight"`；
* PDF 中字体尽量保留为可编辑文字；
* 代码能够重复运行并得到稳定结果。

---

## 十一、需要避免的情况

Codex 后续绘图时应避免：

* 擅自改成 Seaborn 风格；
* 擅自使用渐变色或复杂配色；
* 擅自去掉顶部和右侧边框；
* 使用过细的折线；
* marker 太小；
* 图例没有阴影；
* 字号过小；
* 图片背景不是纯白；
* 为了“高级感”而偏离师兄图的风格；
* 所有图都机械使用相同坐标范围；
* 不考虑数据分布而固定图例位置；
* 仅输出低分辨率 PNG；
* 只给代码片段而缺失完整运行环境。
