## 2 本版的叙事组织

摘要以噪声、稀疏两项挑战开场，先完整呈现预训练、条件扩散与图重构，再简要带出融合前跨视图学习，最后落在已有实验。SetLoss 只用一个辅助句交代。

引言按“任务价值 → 三类关系及各自作用 → 方法发展 → 两项挑战 → 两个模块 → 三条贡献”推进。三类关系先于方法比较出现，融合先定义再使用；GNNs 和 CL 在首次出现时给出全称。

模块一的中心不是“增加一个损失”，也不是泛泛“采用扩散”，而是把个性化潜在降噪落实为 U-B 二部图连接的重评与筛选。模块二围绕原本存在的有限 U-B 反馈展开，不解释成模块一删边后的补救。

相关工作分为捆绑推荐、推荐去噪与扩散、推荐对比学习三类。每类既交代方法谱系，也说明与本研究的连接；没有把“已有方法完全不处理噪声”或“完全没有跨视图协作”当作创新前提。

DCBR 在英文正文中仅出现于相关工作的一个客观介绍句，并正常引用。没有围绕它组织摘要、引言或贡献，也没有以省略相关研究来支撑“首次提出”的宣称。

## 3 核心表述与证据对应

| 正文表述 | 核对依据 | 保留的边界 |
| --- | --- | --- |
| 预训练 → 潜在偏好构造 → 用户条件扩散 → U-B 重构 | 工作记录第六项；初稿方法；`models/model.py` 中 `LatentDiffusionRebuilder`；训练流程与配置 | 不把当前分支的模块开关视为最终模型定义，不要求先整理代码才能写论文。 |
| 历史捆绑嵌入聚合为偏好向量，以用户嵌入为条件 | `_pool_observed`、`_model_features`、`training_loss` | 扩散对象不是原始 U-B 二值交互向量，也不是单个目标物品嵌入。 |
| SetLoss 约束恢复向量与历史捆绑表示的一致性 | `training_loss` 中逐捆绑余弦相似度的掩码均值 | 它是辅助正则，不提供干净标签，不能宣称保证识别噪声或完整保留全部兴趣。 |
| 精炼偏好重评观测边并重构 U-B 图 | `refine_latent` 与 `rebuild_topk` | 筛选范围是已有观测边；没有写成生成新交互、补全未知边或直接生成捆绑。 |
| 重构 U-B 锚定融合前的 U-B–U-I、U-B–B-I 对比 | `cal_pre_fusion_anchor_cl_loss`；工作记录第五、六项 | 用户和捆绑两侧均有约束；没有写 U-I–B-I 配对、固定教师或严格单向蒸馏。 |
| 三个公开基准上优于所比较的基线 | 初稿表 1 | 限定为已有比较，不升级成对所有最新方法的全面 SOTA 结论。 |
| 组件与交互筛选分析支持设计 | 初稿表 3、图 2(a)–(b)及相关正文 | 去掉图优化的影响随数据集和指标变化，不写“每个模块在所有指标上均提升”。现有结果不是单独的 SetLoss 消融证明。 |
| 最低交互组从模块二获得最大相对收益 | 图 2(c)–(d)的结果、工作记录第五项及用户亲自核实的设置 | 实际比较是完整 DiGO 与去掉模块二，两者都保留模块一；不写统计显著、不声称各组收益严格单调。 |

上述证据中，模型细节用于保证表述落地，已有实验用于限定结果陈述。推荐指标改善与交互筛选对照支持方法的推荐有效性，但不等于已经测得真实噪声边识别准确率；本版没有跨越这一界限。

## 5 对师兄重点批注的处理

| 初稿问题 | 本版处理 |
| --- | --- |
| 为什么研究捆绑推荐、发展脉络过薄 | 从整体需求与预定义捆绑排序出发，补充注意力、图传播与多视图对比的发展。 |
| 三种关系位置靠后，view、relation、signal 混用 | 先定义关系和信息角色，再解释基于关系得到的表示视图；不使用 task-direct 等自造标签。 |
| 挑战一泛化为误点击，且与自身建模相矛盾 | 不把噪声说成捆绑任务独有；围绕 U-B 边进入传播及历史集合支持交互重评展开。 |
| “U-B substantially sparser than U-I” 无依据 | 改为单个用户的历史捆绑反馈有限，不做跨关系密度排序。 |
| fully align 缺少必要性、融合突然出现 | 改为同一实体的跨视图一致性及实体区分；先定义融合，再介绍融合前约束。 |
| 两个设计没有记忆点，贡献过长 | 加粗完整扩散图重构流程与 U-B 锚定的融合前对比；SetLoss 从属于模块一，贡献压成三条。 |
| 相关方法覆盖不足 | 按研究问题组织三类相关工作，补入六篇必要的外部方法，而不是单纯加长文字。 |

## 6 后续章节需要承接的事项

以下事项不阻塞前三部分的第一版，也不是要求现在重做实验或整理代码。

1. **方法章节补齐 SetLoss。** 初稿扩散目标主要呈现恢复损失，后续需补充集合一致性项的定义、权重、作用范围，并同步方法图。现有正文没有声称已经有单独 SetLoss 消融；如要论证其独立收益，需要相应证据，不能从整个模块的消融直接推出。

2. **明确扩散训练与精炼推理的区别。** 当前参考实现训练时执行 Gaussian 扰动与 clean-vector prediction；`refine_latent` 从历史聚合向量出发，按逆序时间步反复预测。前三部分未写“从纯高斯噪声开始采样”，也未擅自规定固定一次或每轮一次的最终图更新调度。方法章节应根据最终采用的算法明确表述。

3. **修正稀疏用户实验的旧文案。** 用户已经确认完整 DiGO 与去掉模块二的模型均保留模块一。后续删除或改正图 2(c)–(d)图注以及正文中“关闭 graph optimization”的错误描述。这里是改文案，不是重新质疑已确认设置。

4. **统一实验数字口径。** 初稿摘要写最大相对提升 10%，表 1 的 Improv. 行包含 11.48%，二者不一致。本版摘要不引用任何最大提升百分比；后续整理实验时统一原始结果、四舍五入与计算基准，不静默挑选一个数字。

5. **保留证据的适用范围。** 图 2 的具体用户组结果来自一项已有分组实验，不外推为三个数据集都完成了同样分析。正文不出现具体数据集名称，但实验章节必须据实写清。图优化消融在个别指标上无提升的情况，也不能在后续改写中抹掉。

6. **文献版本与格式。** RDiffBR 采用 [AAAI 2026 正式出版记录](https://ojs.aaai.org/index.php/AAAI/article/view/38662)，不引用本地文件的结果数字；DiffuRec 的作者仓库引用数据采用 2023 年、卷期为 2024 年 5 月，本版据此保留出版年与期刊期次的区别。[DiffuRec 作者仓库](https://github.com/WHUIR/DiffuRec)；综述暂按实际研读的 2024 年 arXiv v1 引用，当前 [arXiv 记录](https://arxiv.org/abs/2411.00341)已显示 2026 年 v2 获 ACM Computing Surveys 接收，投稿整合时可统一为核验后的正式出版版本。DGMAE 第二作者按所提供 ACM PDF 的印刷姓名“Zhang Haonan”保留，不自行颠倒姓名顺序。
